# ⛅ Cuaca & Radar Dashboard (Weather Web App)

Sebuah *dashboard* pemantau cuaca dan curah hujan interaktif yang dibangun menggunakan Vanilla JavaScript. Aplikasi ini menyajikan data cuaca *real-time*, prakiraan per jam, hingga peta radar awan hujan yang beroperasi secara langsung.

![Weather App Preview](https://via.placeholder.com/1000x500.png?text=Tambahkan+Screenshot+Aplikasi+Cuaca+Anda+Di+Sini)

## ✨ Fitur Utama
* **🌍 Pencarian Lokasi Global:** Mendukung pencarian presisi menggunakan *Geocoding API*.
* **📡 Radar Hujan Interaktif:** Terintegrasi dengan Leaflet.js dan RainViewer untuk melacak pergerakan awan presipitasi secara *live*.
* **📅 Prakiraan Mendetail:** Menampilkan suhu *real-time*, kelembapan, indeks UV, kecepatan angin, serta prakiraan cuaca 7 hari ke depan.
* **📱 Desain Responsif & Modern:** Mengusung antarmuka bergaya *dashboard* yang rapi, *dark mode*, dan sepenuhnya responsif untuk layar HP maupun Desktop.

## 🛠️ Teknologi & API yang Digunakan
* **Frontend:** HTML5, CSS3 (Flexbox & Grid), Vanilla JavaScript (ES6+).
* **Maps Engine:** [Leaflet.js](https://leafletjs.com/)
* **Weather API:** [Open-Meteo API](https://open-meteo.com/) (Data Cuaca & Geocoding)
* **Radar API:** [RainViewer API](https://www.rainviewer.com/api.html) (Layer Peta Hujan)
* **Ikon:** [Phosphor Icons](https://phosphoricons.com/)
